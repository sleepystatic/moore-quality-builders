Place Helvetica Black font files here:
- HelveticaBlack.woff2 (preferred for web)
- HelveticaBlack.ttf (fallback)

Note: Helvetica is a licensed font. You'll need to legally obtain the font files.
Free alternatives that look similar:
- Arial Black (system font, no file needed)
- Roboto Black (Google Fonts, free)
- Inter Black (Google Fonts, free)

If using a free alternative, update the @font-face src in style.css accordingly.
